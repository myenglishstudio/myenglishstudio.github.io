Grammar Practice: 'To Be' vs 'Do / Does'

📌 Grammar Rule: When to use 'To Be' vs 'Do / Does'

  • Use 'To Be' (am / is / are) with Nouns (a doctor), Adjectives (happy, cold), Prepositional Phrases / Places (at home, in London), and Verb-ING (working, raining).
  • Use 'Do / Does' with Base Verbs (like, work, play, have, travel, live) to form Present Simple questions.
