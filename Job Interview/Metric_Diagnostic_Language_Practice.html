Metric Diagnostic Language Practice

Task 1: Stage Classification

Read each phrase and select its correct functional stage in a Metric Diagnostic framework.

Task 2: Choose the Correct Word

Select the correct word from each dropdown pair to complete the diagnostic phrase.

Task 3: Missing Words (Fill-in-the-Blanks)

Fill in the missing words using the initial letter prompts inside each box, then click "Check" for feedback.

Task 4: Rearrange Words to Build Sentences

Drag and drop the words into the correct logical order to rebuild the original diagnostic phrases.
