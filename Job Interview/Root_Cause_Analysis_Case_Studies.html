Scenario A: YouTube Shorts Engagement Drop

On Tuesday morning, automated monitoring flags a 14% drop in YouTube Shorts total daily watch time WoW, while total Daily Active Viewers (DAV) opening the Shorts tab remains flat.

Steps revealed: 0 / 5
[1. Validate Data]

Before investigating user behaviour, I would first rule out logging issues or client-side telemetry drops by running a sanity check on telemetry ingestion pipelines.

[2. Segment Data]

Next, I would slice and dice the data along key dimensions like App Version, Mobile OS (iOS vs. Android), and Geographic Region to isolate whether the issue is widespread or localized.

[3. Decompose Metric]

To understand what's driving this, I need to decompose the top-line metric: Total Watch Time = DAV × Shorts Watched per DAV × Average Watch Duration per Short. Since DAV is flat, the drop must be carried by completion rates or session depth.

[4. Test Hypotheses]

Given that traffic is stable but watch duration declined, an algorithmic feed recommendation failure could be serving irrelevant content, or a video player buffering bug must have caused early user drop-offs.

[5. Action & Mitigation]

I recommend rolling back the latest recommendation model update and deploying a hotfix for any media playback latency issues.
